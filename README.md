Strategy - проект на Java

Описание проекта

Проект Strategy представляет собой простую модель боевого отряда, состоящего из трёх типов бойцов: лучника, копейщика и всадника.

В ходе работы был доработан исходный код программы и реализован шаблон проектирования Factory Method (Фабричный метод).

Проделанная работа

В рамках проекта были выполнены следующие изменения:

Создан абстрактный класс Unit, который содержит общие характеристики бойцов: здоровье, атаку и броню.

Классы Archer, Spearman и Horseman переведены на наследование от Unit.

Общая логика атаки вынесена в базовый класс.

Исправлена инициализация списка бойцов в классе Squad.

Добавлена проверка урона, чтобы он не мог быть отрицательным.

Реализован шаблон проектирования Factory Method:

UnitFactory - абстрактная фабрика;

ArcherFactory - создание лучников;

SpearmanFactory - создание копейщиков;

HorsemanFactory - создание всадников.
